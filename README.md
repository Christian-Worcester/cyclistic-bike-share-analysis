# Cyclistic Bike-Share Analysis

## Project Overview

This project analyzes Cyclistic bike-share usage data to identify differences between casual riders and annual members. The goal is to understand rider behavior and develop data-driven recommendations for converting casual riders into annual members.

## Tools Used

- SQL — data cleaning, analysis, and aggregation
- Tableau Public — data visualization and dashboard creation
- GitHub — project documentation and portfolio

## Analysis

The analysis examines:

- Ride volume by rider type
- Ride volume by day of week
- Ride volume by hour of day

## Key Findings

The analysis compares how casual riders and annual members use the Cyclistic bike-share service, including differences in when and how frequently each rider group uses the service.

## Recommendations

Based on the observed differences in rider behavior, Cyclistic can use targeted membership marketing to encourage casual riders to become annual members, particularly during periods and usage patterns where casual rider activity is highest.
